# Support

Use GitHub Discussions for setup questions, deployment patterns, and review
quality tuning.

Use GitHub Issues for reproducible bugs or focused feature requests.

When asking for help:

- include the command you ran
- include masked logs from `var/log`
- include the relevant `config/env.toml` shape with secret values removed
- say whether the run used Codex CLI or Claude CLI
- say whether the review was dry-run or posting mode

Do not include private repository names, customer names, or raw tokens.
