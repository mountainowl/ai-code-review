# Code Of Conduct

This project expects direct, respectful technical collaboration.

## Expected Behavior

- Keep feedback specific and actionable.
- Assume code, logs, prompts, and screenshots may contain sensitive context.
- Disagree with evidence.
- Help maintain a small, generic tool instead of adding repo-specific behavior.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing secrets or private repository details.
- Repeated off-topic promotion or spam.
- Intentionally disruptive issues, pull requests, or comments.

## Enforcement

Maintainers may edit, hide, or remove content that violates this code. Repeated
or severe violations can lead to blocking from the project.
